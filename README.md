# Notify Hub — Native Windows Notification Manager

**Notify Hub** is a production-grade, native Windows desktop application that captures, categorizes, stores, tracks, and forwards desktop notifications generated by installed applications.

Running continuously in the background with negligible system footprint, Notify Hub ensures you **never lose track of an incoming notification**.

---

## 🌟 Key Capabilities

### 1. Universal Notification Monitoring Engine
- **Native Windows API:** Directly interfaces with the Windows WinRT `Windows.UI.Notifications.Management.UserNotificationListener` platform.
- **Continuous Monitoring:** Captures all accessible notifications across installed applications (WhatsApp, Telegram, Slack, Microsoft Teams, Outlook, Chrome, Edge, Windows Defender, etc.).
- **Dual Capture Architecture:** Combines instant OS event callbacks (`NotificationChanged`) with a background 3.5s sync fallback to guarantee zero missed alerts.
- **Deterministic Deduplication:** Multi-layer deduplication (memory hash + SQLite unique constraint) prevents redundant records.
- **Background Execution:** Fully decoupled from the UI. Minimizing or closing the dashboard keeps the engine running in the Windows System Tray.

### 2. Local SQLite Persistence
- **Zero Cloud Dependency:** All notification history is stored locally in `%LOCALAPPDATA%\NotifyHub\notifyhub.db`.
- **Crash Resistance:** Configured with Write-Ahead Logging (`PRAGMA journal_mode=WAL; PRAGMA synchronous=NORMAL;`) for maximum resilience.
- **Indexed Search:** Instant querying across thousands of records via B-tree indexes on `ReceivedAt`, `Status`, `Category`, `AppName`, and `NotificationId`.
- **Automated Backup & Restore:** Built-in `VACUUM INTO` backup engine and database restoration capabilities.

### 3. Smart Categorization & Priority Engine
- **10 Default Categories:**
  1. *Work & Business* (Slack, Teams, Trello, Jira, GitHub, etc.)
  2. *Emails* (Outlook, Thunderbird, Mail, Gmail)
  3. *Messages & Communication* (WhatsApp, Telegram, Signal, Discord, etc.)
  4. *Social Media* (Twitter/X, Instagram, Facebook, LinkedIn, Reddit)
  5. *Finance & Banking* (Banks, PayPal, Revolut, Stripe, Crypto)
  6. *System & Security* (Windows Security, Defender, Firewall, Updates)
  7. *Calendar & Reminders* (Calendar, Clock, Reminders, Alarms)
  8. *Shopping & Orders* (Amazon, eBay, FedEx, DHL, UPS)
  9. *Personal* (Family, Contacts, Photos)
  10. *Other* (Default fallback)
- **Offline Rule Engine:** Create custom application, keyword, or regular expression rules without cloud or AI dependencies.
- **Intelligent Priority Heuristics:** Automatically escalates Banking OTPs, fraud alerts, security threats, and server crashes to **Urgent** or **High** priority.

### 4. Notification Status & Workflow Management
- **Status Lifecycle:** Every notification is assigned a tracking state: `Pending` ➔ `In Progress` ➔ `Done` ➔ `Archived`.
- **Pending Age Tracking:** Dynamically shows how long an item has remained unresolved (e.g. *"Pending for 3h 15m"*).
- **Personal Notes:** Add custom notes, reminders, or resolution details to any notification.
- **Bulk Actions:** Perform bulk status updates, bulk archiving, or bulk deletion with one click.

### 5. Instant Dual-Channel Forwarding
- **Telegram Forwarding:** Sends newly captured notifications to your private Telegram chat or team group with formatted HTML cards.
- **Email Forwarding:** Dispatches clean, responsive HTML emails via SMTP (Gmail, Outlook 365, or corporate mail servers).
- **Asynchronous & Non-Blocking:** Forwarding executes asynchronously **after** the notification has been safely committed to SQLite. Network downtime never blocks capture or causes notification loss.
- **Delivery Logs & Automatic Retries:** Maintains detailed delivery logs with attempt counts and error details, offering single-click retry for failed items.

### 6. Modern Fluent Windows Interface
- **KPI Overview Cards:** Real-time metrics for *Total Captured*, *Pending Action*, *In Progress*, *Completed*, and *Received Today*.
- **Comprehensive Filtering:** Live search, source application dropdown, category selector, status selector, priority selector, and date range filters.
- **Slide-In Details Drawer:** Inspect complete notification titles, bodies, metadata, notes editor, and forwarding history.
- **Export Engine:** One-click export to standard **CSV** and **Excel XML Spreadsheet** formats.
- **System Tray Integration:** Unobtrusive system tray icon with context menu options (*Open Dashboard*, *Pause/Resume Monitoring*, *Settings*, *Exit*).

### 7. Security & Privacy
- **Windows Credential Manager:** Sensitive credentials (Telegram Bot Tokens, SMTP Passwords) are stored securely using native Windows Credential Manager P/Invoke APIs (`Advapi32.dll`) with DPAPI fallback.
- **Zero Plaintext Credentials:** No secrets or API keys are ever stored in plain text.

## 🚀 Installation & Quick Start

Simply run the single all-in-one installer:

```text
NotifyHubMainInstaller.exe
```

1. Double-click `NotifyHubMainInstaller.exe`.
2. The native setup wizard will open.
3. Select your installation folder (defaults to `%LOCALAPPDATA%\Programs\NotifyHub`).
4. Click **Install**.
   - Automatically extracts all self-contained application binaries.
   - Creates a Start Menu shortcut (`Notify Hub`).
   - Creates a Desktop shortcut (`Notify Hub`).
   - Creates an uninstaller (`Uninstall.bat`).
   - Optionally launches Notify Hub immediately.

For unattended/silent installation from command prompt or scripts:
```cmd
NotifyHubMainInstaller.exe /silent
```

## 🛠️ Building from Source

### Prerequisites
- Windows 10 (version 19041 or higher) / Windows 11
- .NET 9.0 SDK installed

### Compilation Commands
```powershell
# Restore dependencies
dotnet restore src/NotifyHub/NotifyHub.csproj

# Build Release binary
dotnet build src/NotifyHub/NotifyHub.csproj -c Release

# Run automated functional test suite
dotnet run --project tests/NotifyHub.Tests/NotifyHub.Tests.csproj

# Publish self-contained/framework-dependent distribution
dotnet publish src/NotifyHub/NotifyHub.csproj -c Release -o dist/NotifyHub
```
